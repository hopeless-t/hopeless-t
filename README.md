# hopeless-t

I build small, inspectable systems for AI-assisted work.

My work focuses on verification, bounded authority, reproducible experiments, and turning ambiguous workflows into testable contracts.

## Selected work

### [NazeYatta](https://github.com/hopeless-t/NazeYatta)

Preflight and post-action verification for AI workers and automation.

`UNKNOWN` stays `UNKNOWN`. A passing check does not create execution authority.

### [ChatGPT Conversation Refresh PoC](https://github.com/hopeless-t/chatgpt-refresh-poc)

A small Swift behavior-contract prototype for safe, read-only conversation resynchronization.

`Refresh = Observe + Reconcile + Render`

### [Finite RAM Lab](https://github.com/hopeless-t/finite-ram-lab)

Reproducible systems experiments around memory pressure, residency, reclaim behavior, and future-demand mismatch.

## Working principles

- UNKNOWN stays UNKNOWN.
- Evidence does not create authority.
- Observation comes before intervention.
- Execution and verification are separate responsibilities.
- A successful run is not automatically a successful experiment.
- Negative results are results.
