## Reading this page

This is not a skills matrix or a self-rating.

It is a map from statements about how I work to artifacts another person can inspect.

The intended standard is simple:

```text
Claim
  ↓
Public artifact
  ↓
Inspectable code / tests / evidence
```

If a claim cannot yet be supported that way, it does not need to appear here.
